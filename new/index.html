ariadne-ts

Beautiful, Rust-style compiler diagnostics for TypeScript

View on GitHub npm Package

About

ariadne-ts is a TypeScript library for generating elegant, informative, and context-aware error reports. Create beautiful diagnostic messages with the style and clarity of Rust's compiler output.

This library is a direct port of the excellent Rust crate ariadne, bringing professional-grade diagnostics to the JavaScript ecosystem.

Features

📌 Multi-Label Diagnostics

Attach multiple labels to highlight related code locations in a single report.

🎨 Custom Colors & Themes

Full control over colors and styling to match your tool's branding.

🔗 Complex Pointer Support

Create clear, non-overlapping annotations even for complex nested code.

📝 Rich Context

Add notes, hints, and helpful guidance to guide users toward solutions.

⚡ Framework Agnostic

Pure TypeScript with minimal dependencies, works anywhere.

🛡️ Type Safe

Full TypeScript support with comprehensive type definitions.

Quick Start

Install from npm:

npm install ariadne-ts

Or with yarn:

yarn add ariadne-ts

Example Usage

import { Label, Range, Report, ReportKind, Source } from "ariadne-ts"

Report.build(ReportKind.Error, "sample.tao", 34)
  .with_code(3)
  .with_message("Incompatible types")
  .with_label(Label.from(["sample.tao", Range.new(32, 33)])
    .with_message("This is of type Nat"))
  .with_label(Label.from(["sample.tao", Range.new(42, 45)])
    .with_message("This is of type Str"))
  .with_note("Outputs must coerce to the same type")
  .finish()
  .print(["sample.tao", Source.from(sourceCode)])

Use Cases

  • 🔨 Language Compilers: Generate diagnostic output for custom programming languages
  • 🔍 Linters & Analyzers: Report issues in code with rich context and suggestions
  • ✅ Type Checkers: Display type mismatches and related locations
  • 🧪 Test Frameworks: Format test failures with code context
  • 📋 Code Generators: Report errors during code generation with source mapping
